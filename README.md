# 印刷拼版预检与打样轮次审批平台

面向印刷生产团队的拼版工作台，支持页面尺寸与印刷规格、Canvas 版位编辑、出血/安全区/折手/页码检查、打样反馈、版本并排对比、审批锁定和可恢复导出任务。

## 技术栈

Vue 3 + PrimeVue + Pinia + Vue Router + TanStack Query + Axios + Canvas + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62050`。

## 核心工作流

- 导入页面尺寸、出血、安全区、折手和装订方向，在 Canvas 中拖拽版位。
- 自动检查页面缺失、出血不足、页序冲突、版位重叠和装订错误。
- 每轮打样记录样张照片、色差反馈、修正说明和负责人决定。
- 版本并排对比、审批锁定，并恢复中断的导出任务。

## 夜班可恢复换纸

- **批次登记即冻结**：新纸批次登记后纸宽、纸高、克重不可改，规格变化只能追加新批次。
- **换纸只失效受影响组**：确认前预览越界跨页组；纸批次一切换，仅受影响跨页组版位标记失效并保留旧纸批号，重算拉回安全区、出血达标后按组重新确认，其余版位保留。
- **先到者占用**：两人同时确认换纸时，先到者通过跨标签页锁（BroadcastChannel + 心跳 TTL）占用，后到者只读查看受影响版位与导出分片。
- **打样留依据**：每轮打样记录纸批号、纸张快照与版位摘要；换纸后旧轮次标“旧依据”仅供追溯。
- **分片级可恢复导出**：任务与每个分片都带纸批号和版位摘要；写盘失败回退到最后确认分片继续，已完成分片在纸批号与摘要一致时复用、不一致则重置；缺纸批号或版位摘要的旧任务先归“待复核”，补依据前不续传。

## 逻辑验证

```bash
node scripts/e2e-check.cjs   # 换纸全流程（登记→占用→失效→重算→确认→待复核）
node scripts/api-check.cjs   # 分片恢复、失败重试、依据复用/重置、rebase
```
